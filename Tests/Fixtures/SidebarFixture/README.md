# Sidebar Fixture

The [sidebar fixture](https://www.swift.org/documentation/) package exercises
the static documentation renderer with a small set of geometry types.

## Installation

Add to your `Package.swift`:

```swift
dependencies: [
    .package(url: "https://example.com/sidebar-fixture.git",
             branch: "main"),
]
```

## Requirements

- Swift 6.0 or later

- macOS 15.0+ or Linux
